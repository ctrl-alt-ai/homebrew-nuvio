# Local Nuvio

## How do I install these formulae?

`brew install local/nuvio/<formula>`

Or `brew tap local/nuvio` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "local/nuvio"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
